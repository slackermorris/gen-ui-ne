Problem

The renderer rebuilt every node via an inline renderElement() call and spun up the Effect runtime (RuntimeClient.runSync) once per element just to read a synchronous in-memory map, so React preserved no identity and effect machinery leaked into render.

Solution

Resolve the registry lookup once at a stable seam, then render each spec node through a named Element component that recurses by rendering nested Elements — identity preserved, runtime out of the render path.

Wins

  • Deep module: tiny {spec,id} interface
  • Identity preserved across re-renders
  • Runtime resolved once, not per node
  • Effect seam out of render path
  • Locality: recursion in one module
  • Pure lookup, leverage at every node
